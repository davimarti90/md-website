# MD Interstate Moving — Website (Next.js 14)

Direct movers. No Broker Fee. Same-day NJ & Interstate.  
Domain: https://mdinterstatemoving.com

## Run locally
```bash
npm i
npm run dev
```

## Env vars (`.env.local` and Vercel)
```
MAIL_FROM=admin@mdinterstatemoving.com
MAIL_FROM_NAME=MD Interstate Moving
MAIL_APP_PASSWORD=your-gmail-app-password
MAIL_TO=support@mdinterstatemoving.com
```

## Deploy (Vercel)
- Import repo, add env vars (Production & Preview), redeploy.
